# 尾牙主桌排位系統

用拖拉方式安排尾牙賓客座位的網頁工具。Excel 匯入賓客資料、圓桌視覺化排位、出席狀態管理、匯出 Excel / 圖片 / 專案檔。

## 功能

- **Excel 匯入賓客名單**：欄位對應「單位 / 頭銜 / 姓名 / 飲食習慣 / 聯絡方式 / 備註」
- **左側待排清單**：依單位自動配色，可拖拉到桌位
- **出席狀態管理**：獨立分頁，on/off 切換開關；不出席的賓客若已入座會顯示灰色
- **圓桌排位圖**：桌名下方顯示「目前人數 / 總座位數」
- **拖拉交換**：
  - 賓客卡拖到空位 → 入座
  - 座位拖到另一座位 → 兩人互換
  - 拖動桌名區塊到另一桌 → 整桌座位互換
  - 座位拖回左側清單 → 退回待排
- **右鍵查看/編輯資料**：飲食禁忌、備註（如幾點到/幾點離席）、出席開關、刪除、移出座位
- **新增貴賓** 按鈕（匯入後追加使用）
- **新增桌次**：可選 8/10/12/16 人
- **重置排位**：所有人退回待排清單（不刪除名單）；另有「清空全部資料」做完全重置
- **匯出**：整體專案（JSON，可再匯入還原）、單一桌次排位圖（PNG）、完整 Excel（含已排位/未排位兩個工作表）
- **顯示/隱藏頭銜** 切換
- **縮放**：畫面右下角可縮放整體排位圖
- 所有資料會自動存在瀏覽器 localStorage，重新整理不會遺失（清空資料才會重置）

## 本機執行

需先安裝 [Node.js](https://nodejs.org/)（建議 v18 以上）。

```bash
npm install
npm run dev
```

打開終端機顯示的網址（通常是 http://localhost:5173）即可使用。

## 建置正式版

```bash
npm run build
npm run preview   # 可選，本機預覽建置結果
```

建置完成的靜態檔案會在 `dist/` 資料夾，可以部署到任何靜態網站空間（GitHub Pages、Netlify、Vercel...）。

## 上傳到 GitHub

```bash
git init
git add .
git commit -m "尾牙主桌排位系統"
git branch -M main
git remote add origin https://github.com/<你的帳號>/<repo名稱>.git
git push -u origin main
```

### 部署到 GitHub Pages（可選）

1. 在 `vite.config.js` 加上 `base: '/<repo名稱>/'`
2. 安裝並使用 `gh-pages`，或用 GitHub Actions 自動建置部署到 `gh-pages` 分支

## Excel 匯入格式範例

| 單位 | 頭銜 | 姓名 | 飲食習慣 | 聯絡方式 | 備註 |
|---|---|---|---|---|---|
| 業務部 | 經理 | 王小明 | 不吃牛 | 0912-345-678 | 20:00 前到 |
| 財務部 | 協理 | 林美美 |  | 0955-111-222 |  |

欄位名稱大小寫、順序不拘，只要包含上述關鍵字即可自動對應（也支援「職稱」「電話」「備注」等別名）。

## 技術棧

- React 18 + Vite
- [SheetJS (xlsx)](https://github.com/SheetJS/sheetjs) 處理 Excel 匯入匯出
- 純 Canvas 2D 繪製單桌匯出圖片，不依賴額外截圖套件
- 原生 HTML5 拖拉 API（不需額外拖拉套件）
